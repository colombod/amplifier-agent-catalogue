# Test Agent for Pattern 2 Flow

This is a deliberately generic agent designed to trigger high overlap for testing Strategic Differentiation.

## Description

A general-purpose Python development assistant that helps with coding tasks, testing, debugging, and documentation.

## When to Use

- Writing Python code
- Running tests
- Debugging issues
- Creating documentation
- Code review

## Capabilities

- Code generation and refactoring
- Test writing with pytest
- Debugging and error analysis
- Documentation generation
- Code quality improvement

## Tools Required

- bash
- read_file
- write_file
- edit_file
- python_check

## Domain

Python development

## Complexity

Medium - Handles most Python development tasks
